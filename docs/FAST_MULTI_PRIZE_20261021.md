# 開獎加速、流暢度與同輪多獎（2026-10-21）

## 開獎動畫

- 前導 1.2 秒、每球 2.4 秒，六球約 15.6 秒；原為約 27.6 秒。球槽的物理移動速度提高約兩倍，吸球管道通過時間從約 1.93 秒降至約 1.10 秒。
- 投影或其他活動顯示時，停止被遮住的主頁機台；專用投影不會再另外建立隱藏的主頁機台。
- 背景／機身快取為靜態圖層，前景玻璃裁切成小範圍快取，保留球體及出球特寫的動態。手機畫布使用 720×432，桌機 1000×600。
- 相同輪詢資料不重設動畫回呼。修正 Date.now 的毫秒取整造成 16.67／33.33ms 排程跳幀，桌機目標 60fps、手機 30fps；實際幀率仍取決於設備。
- Native Canvas 同場景逐幀比較（此主機，非手機量測）舊版中位數 2.28ms／P95 2.98ms，新版 2.09ms／P95 2.83ms。主要改善另包含避免雙機同繪與穩定排程。

## 同一輪開多個獎

主持人→樂透控制：先截止選號，輸入選填獎項名稱（如二獎），按開始開獎；動畫結束後填下一個獎項名稱，再按「④ 開下一個獎（保留彩券）」。賓客不需重新投注。

既有彩券不變，預設排除本輪已中獎賓客。相同六碼若有多人會沿用原規則一起中獎，全部列入排除名單。獎項、號碼、得獎者歷史存於既有 lottery 設定，主持人及賓客可查看；當次開完才顯示當次紀錄。

舊版已完成的最後一次開獎會在第一次續開時補入歷史，原中獎賓客也排除。多人同時按開獎以條件寫入鎖保護，不會重複發布；發佈失敗會恢復原狀態。動畫中不能續開或重設；抽完全部賓客後保留彩券與得獎紀錄，顯示無尚未中獎彩券。

「重開新一輪」才清空全部彩券與本輪全部獎項紀錄，確認文案已明確區分。照片、報到及祝福不受本次功能影響。
