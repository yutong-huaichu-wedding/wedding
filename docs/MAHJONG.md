# 摸麻將猜牌環節（2026-10-19）

這次是實體互動：宇童與懷筑拿著麻將盤給賓客摸牌、說出牌名，由新人手動判斷答案及切換投影。

## 上線後操作

1. 電腦登入婚禮主持人後台，選「摸麻將」，按「在這台電腦開啟摸麻將投影」。也可從「投影」選「摸麻將猜牌畫面」。
2. 手機登入同一網站的主持人後台，選「摸麻將」。
3. 賓客摸牌前按「猜猜是什麼牌」，投影顯示問號麻將與提示。
4. 賓客回答後，依實際結果按「答對了」或「答錯了」。
5. 下一位開始時，再按「猜猜是什麼牌」。

三種畫面都會停留到主持人再次操作，不計時、不自動判斷、不自動換下一位，也不隨機抽牌。
電腦和手機都需連網，不必使用相同 Wi-Fi。同步沿用婚禮主站輪詢，通常需等待下一次更新；保持兩邊頁面開啟。
本環節沒有內建音效，避免現場突然出聲。新人直接展示摸出的實體牌即可，網頁不必先設定牌名。
