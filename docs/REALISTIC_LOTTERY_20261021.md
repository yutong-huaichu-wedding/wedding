# 參考實體機台的擬真開獎（2026-10-21）

依使用者 image(5).png 參考：長筒透明氣流槽、黑色金屬機身、紅球白字、出球特寫、六球承接槽。

## 呈現

lottery-draw.js 改由 Canvas 2D 繪製攝影棚機台：壓克力筒壁反光、銀色筒蓋與底座、黑色機身及壓力顯示、透明吸球管、右側球體特寫與六球承接槽。紅球有明暗、反光與隨旋轉變化的重複白色號碼。

內部球體以三維位置和速度計算氣流、重力、等質量碰撞與筒壁反彈；依深度排序並縮放繪製。選中球從當下位置被吸進管道，並在特寫鏡頭公布號碼。開完後停風，剩餘球短暫落回底部。

共用原先 2.4 秒前導＋每顆 4.2 秒時間軸，沿用伺服器提供的 result／startedAt，晚加入直接跟隨當前進度。保留原開獎規則與無手機代投，不更動正式資料。

小球紋理預先快取，降低手機每幀重畫文字及反光的成本。動畫繪圖上限約 30fps，背景頁停止排幀，關閉／切換活動清理，開獎及短暫落球結束後停止持續動畫；繪圖在裝置本機進行，不增加伺服器同步請求。尊重減少動態效果設定。
