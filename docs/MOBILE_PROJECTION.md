## 現場操作

1. 手機開婚禮網站，登入主持人控制台，再進入「小貓迷因問答」。
2. 若自行更換過的題庫在電腦：先在電腦匯出含照片影片的題庫備份，再在手機匯入。手機的題庫和順序是此次出題來源。
3. 手機按「啟用手機跨裝置同步」，再按「複製連結」。將這個專用投影連結傳到投影電腦並開啟。請使用完整連結，不能只開不含參數的小貓頁。
4. 電腦按一次「啟用投影音效」，確認音量並進入全螢幕。電腦不必登入主持人。
5. 手機按「出題／上一題／下一題／公布解答＋播放有聲影片」，電腦會同步更新。公布後手機預覽內「再播一次」可遙控電腦重播；「主持人耳機試音」仍只在手機試聽。
6. 等手機顯示「電腦投影已連線」，再進行正式遊戲。第一次選題會上傳該題照片、影片；首次播放還需電腦下載影片，請事先逐題走過一次及試聽。

兩台裝置皆需連網，可以使用不同網路。請保持手機頁面在前景、不鎖定螢幕。
如瀏覽器阻擋聲音，請在電腦按「啟用投影音效」或答案下方「再播一次」。
投影連結只供顯示，無主持人登入無法送出控制指令；避免將投影連結當作賓客 QR Code 分享。

## 中斷與恢復

- 網路恢復後會自動重試最新指令，舊題目的慢上傳不會蓋掉後來選的題目。
- 電腦重整或重新開啟同一投影連結，會恢復目前題目及答案顯示；不會突然重播過去的聲音。按手機「再播一次」即可播放。
- 手機重整後需再次按「啟用手機跨裝置同步」，會從手機目前預覽的題目重新出題。同一分頁重整會沿用投影連結；若重開新分頁，請重新複製連結到電腦。
- 主持人登入逾期，請回婚禮後台重新登入，再回本頁；網路同步將重試。請勿清除瀏覽器資料，以免遺失本機題庫。
- 小貓遊戲仍可不啟用雲端、使用同台電腦的獨立投影。

## 修改內容與驗證

- 新增雲端投影狀態 API，以既有 settings 表保存隨機房間的目前狀態，不更動樂透、問答、賓客、相簿資料。
- 新增照片及影片上傳／讀取 API，使用既有 R2 的 cat-memes/ 前綴，依內容雜湊去重；只有主持人可上傳與控制，支援影片 byte-range 讀取。
- 題庫編輯、順序與完整備份繼續保存在主持人瀏覽器；目前不是完整雲端題庫管理。上傳到雲端的素材不會因關頁而刪除，房間顯示狀態超過 24 小時不再提供。
- 未公布前不向投影狀態傳送解答文字、答案網址或本機 blob URL。素材透過含雜湊的網址提供，並非私人加密儲存空間。
- 一次僅用一支手機控制同一房間。切換主持人手機時，先匯入題庫並以新連結重新連接投影。
- 同步採短輪詢；網路和影片載入會產生延遲，不是兩台裝置逐格鎖定的影片播放。聲音只需由投影電腦輸出。
- 手機操作按鈕提前，電腦投影版面適配單一畫面；持續沿用同一個影片播放器以協助行動瀏覽器的音效授權。
- 本機自動測試 48 項通過，包含原婚禮功能回歸、獨立控制端與投影端、連續換題、斷線重試、解答隱藏、權限及影片分段讀取。
- TypeScript、正式建置及新增後端／傳輸模組的 ESLint 已檢查。
- 尚未在正式站、實體 iPhone／Android 及婚宴投影機驗收。部署後請使用兩台真實裝置走過上述流程，尤其確認喇叭及有聲影片播放。
