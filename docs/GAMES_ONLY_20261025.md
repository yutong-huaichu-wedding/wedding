# 婚禮網站遊戲範圍｜2026-10-25

本機工作副本依使用者決定，只保留以下三種婚禮遊戲：

- **幸福大樂透**：賓客選號、主持人代投、多獎開獎與投影。
- **小貓迷因**：原有題目、影片、主持人手機與電腦投影同步。
- **麻將問答**：摸麻將及五題聽牌問答，維持主持人手動控制與投影。

快問快答、網站內 Kahoot 加入入口、獨立網頁搶答已從頁面移除。舊遊戲 API 操作會回 HTTP 410，主持人無法再把活動或投影切換到舊模式。`/api/activity` 不再查詢問答或參賽名冊，`/api/state` 不再讀取問答題庫、答案與 Kahoot 設定。保留賓客報到、相簿、祝福、主持人後台及投影等其他網站功能。

**正式資料保留**：沒有執行 D1 遷移、重設或刪除。既有快問快答題目與答題紀錄仍在正式 D1；先前流量測試建立的 300 名測試賓客及其加入紀錄也仍在，名稱前綴為 `LT-MVNSMJ55-`、`LTQ-MVNTG67V-`。移除功能不會自動清掉這些紀錄。

本次只修改工作區原始碼，**尚未部署**，正式網站目前仍是舊版本。部署後仍須實際檢查手機、主持人與投影三種畫面。原始交接包中的舊功能說明與負載測試報告留作歷史紀錄。
