# 遊戲專用QR與原頁雙入口（2026-10-22）

賓客可選：原婚禮首頁按「🎮進入現場遊戲」，或活動開始前掃投影上的遊戲QR。兩種入口共用同一個活動、題目、作答與樂透資料，不建立另一場遊戲。

遊戲QR網址：https://yutong-huaichu-wedding.yutong-huaizhu-1212.workers.dev/wedding_1212?play=1

同一瀏覽器已報到者沿用該瀏覽器的賓客憑證，不用再報到。第一次進來先姓名＋頭像報到，再接進遊戲；若攝影機開啟另一個瀏覽器或LINE內建瀏覽器，不能保證共用登入資料，可能需重新報到。原網址QR繼續用於入席；遊戲QR不含帳號憑證、有效期限或第三方短網址。

專用入口在接待階段顯示「現場遊戲準備中」，保持前景等主持人開始後自動進問答、搶答或樂透。原網頁按進遊戲有相同行為；沒有報到會先導向報到。

主持人控制台及小貓控制頁的活動控制下方新增「投影遊戲 QR Code」與「複製遊戲入口」。按投影QR只切電腦投影，不清除或重開目前活動。建議先選遊戲階段，再顯示QR供大家加入；快問快答按出題／下一題後會自動切回題目投影。小貓在小貓頁出題、麻將在麻將頁出題、樂透正式開獎亦可接回內容。
