# 小貓題目與答案載入改善（2026-10-20）

本更新已與 GitHub main 0824efacea3f31fa7010a81206f4afdb44944d11 的小貓相關原始碼比對；尚需透過原本 GitHub → Cloudflare 流程部署。

## 改善內容

- 先同步題目圖片，不再等整支答案影片上傳完成才顯示題目。答案於背景上傳，不阻塞換題；過期的上傳結果不會把投影拉回舊題。
- 猜題期間，電腦接收目前題目的內部影片網址，使用原來的隱藏播放器提前載入。此時不播放、不顯示影片或答案文字；公布後才移入主畫面並播放。影片網址本身可從網路請求取得，並非防作弊機制。
- 公布、重播時保留同一播放器的來源，盡量沿用已緩衝資料。瀏覽器仍可依網路、記憶體與預載策略決定下載量，無法保證整支影片都已下載。
- 手機先計算檔案內容雜湊，以 HEAD 查詢雲端是否已有相同檔案。重新整理或匯入相同素材後，已有檔案不必再完整上傳。
- 圖片與影片發生載入錯誤，或 20 秒沒有就緒／進展時，最多自動重試三次。已切走的圖片不再重試；答案尚未公布時，重試也不發出聲音。錯誤訊息可在答案公布前看見。
- 固定投影入口、手機連動、音效授權方式與隱藏原生播放控制列均沿用。

## 更新方式

1. 解壓縮 wedding-cat-loading-fix-20261020.zip。
2. 將其中 app、lib、public、tests、docs 五個資料夾拖入原 GitHub 專案根目錄，上傳覆蓋並提交。請上傳資料夾中的檔案，不要只上傳 ZIP，也不要多包一層同名資料夾。
3. 等候原本 Cloudflare 部署成功後，手機和電腦都關閉舊分頁，從原網站重新進入。
4. 電腦開啟原本的固定「電腦專用投影」；手機登入主持人，進入小貓問答並出題。

不需調整 D1／R2 綁定，不需執行資料庫遷移或清空任何資料。只需上傳這次更新包，無需再次上傳整套影片。

## 現場準備

- 開場前，用實際操作手機及投影電腦把所有題目依序出題、公布並聽完。先確認素材都上傳過且每個自訂檔案能播放。
- 演練後保留投影分頁。正式出題後可讓賓客猜題幾秒，讓答案影片有預載時間。
- 大檔仍受手機上傳及電腦下載速度限制。可將素材剪到需要的片段；檔案目標可先抓題目動圖 1–3 MB、答案影片 5–10 MB 以內，再按清晰度調整；這是建議目標，原本 8 MB／50 MB 上限不變。
- 若僅同一題持續失敗，先在編輯區試播；必要時換檔。自動重試無法修復損壞或瀏覽器無法解碼的影片。

## 驗證

自動測試涵蓋：慢速答案上傳仍先出圖、背景上傳不阻塞換題、內容相同的素材跨頁面重新開啟後免上傳、內部預載網址驗證、答案文字隱藏、預載不播放、公布／重播不重設影片來源、載入重試及切題取消舊重試；並回歸原有主持登入、手機固定投影、麻將、樂透、Kahoot、題庫排序與備份流程。

另執行 TypeScript 檢查與正式建置。自動化驗證使用模擬播放器及實際 API／SQLite；尚未在使用者的手機、現場電腦與正式網路上試播。
