# 海洋藍主題與祝福煙火（2026-10-20）

## 外觀

全站改用珍珠白、淺海藍、海洋藍與少量暖沙色；首頁有柔和海面波浪，按鈕、選號、彩球、報到頭像、後台、小貓及投影一併調整。麻將答對／答錯保留不同顏色，但改成與藍色相容的色系；Kahoot 保留品牌紫色。

祝福牆改成深海夜空，有星光、海面與煙火的微光，不加入爆炸音效。每朵煙火對應一則已儲存的真實祝福，綻放後顯示文字、姓名與頭像。無留言時顯示等待提示，不生成假祝福。

## 操作

- 平時約每 8 秒發射一朵，升空約 2.6 秒後自動綻放；已有祝福會輪播。
- 點擊升空中的煙火，立即綻放顯示該則祝福，並將下一朵自動發射提前至約 1.2 秒後。
- 「再發射一朵」可直接發射下一則；「暫停自動／繼續自動」保留手動操作。
- 新留言（包含樂透投注附帶的祝福）在畫面讀取後優先播放。原本完整留言清單與主持人刪除功能保留。
- 手機祝福牆與電腦固定投影都採用此呈現。祝福名單使用同一個雲端資料，動畫時序則各畫面獨立；手動點擊加速目前操作的畫面，不會遠端代點另一台電腦的煙火。

電腦仍使用原本固定投影入口 /wedding_1212?display=1，由手機後台按「祝福煙火牆」切換；也可在祝福頁開啟全螢幕預覽。

## 效能與資料

使用 CSS 動畫與 DOM，不新增持續繪圖迴圈，不引用外部煙火程式庫或素材。最多同時兩個升空煙火、兩組短暫粒子效果，祝福文字每次顯示一則，快速點擊受節流保護。離開祝福頁、切換投影活動或分頁背景時，清除動畫節點與計時器，恢復可見後才繼續。遵守系統減少動態效果設定。

點擊煙火不新增／重複送出留言，也不寫入資料庫。投影 API 額外讀取既有祝福 id，供辨識新留言與移除已刪內容；不改資料表、不需遷移或清空。保留原賓客、相簿、祝福、彩券、管理密碼與固定投影。
