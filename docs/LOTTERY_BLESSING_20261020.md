# 大樂透投注一起送祝福（2026-10-20）

## 賓客操作

大樂透選完六碼後，可在「送給新人的一句祝福」填寫最多 100 字（選填），再按「確認投注與送出祝福」。
成功後，自己的彩券下方會顯示已送出的祝福；訊息也會公開出現在既有祝福牆和祝福彈幕。主持人投注名單可同時查看號碼與祝福，並可透過原本留言管理刪除祝福。

送出時暫停選號與再次提交；失敗時保留號碼和文字，成功才清空草稿。定時更新不會覆蓋正在輸入的文字。未填祝福也能正常投注。原本主持人代投流程仍可使用，不強迫主持人替賓客撰寫祝福。

## 儲存與相容性

沿用 tickets 與 blessings，透過同一 D1 交易寫入。祝福只在該次彩券確實新增成功時建立；投注截止、重複投注、非法內容或交易失敗均不會產生多餘留言。舊彩券、既有祝福、賓客、照片與其他活動資料沿用，不需新增欄位、遷移或重建資料庫。

投注祝福與彩券共用 UUID，查詢時 LEFT JOIN，讓既有彩券無須回填。刪除祝福後，彩券仍存在，但不再顯示該文字；重開樂透清除彩券時，已送出的祝福仍保留於祝福牆。
