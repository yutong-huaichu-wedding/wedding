# 小貓迷因：手機主持人即時預覽（2026-10-21）

## 修正原因

使用者指的是小貓迷因，而非樂透。原 publish() 以 connected() 判斷是否播放本機影片，但 connected() 把「雲端同步已啟用」視為投影已連接。因此手機登入後自動啟用雲端同步，即使沒有電腦，公布／重播也不會播放本機影片。連線初始化亦會主動停止主持人端播放。

## 新行為

- 主持人小貓頁面的題目／GIF 和解答影片可直接觀看，公布及重播不依賴電腦投影。
- 本頁影片預設靜音播放，勾選「開啟這台手機／電腦的聲音」即可在本機有聲播放；投影仍保留自己的音量與音效啟用機制，本機靜音不會傳給投影。
- 換題、公布與重播會捲動到預覽；新增「查看目前畫面」按鈕。手機預覽排在控制區上方。
- 啟用雲端同步與收到本機投影心跳不再停止主持人端預覽；雲端狀態與播放命令仍照常同步。
- 題庫與編輯器保留，影片仍不顯示原生播放控制列。

## 驗證與部署

115 項 Node 測試通過，含雲端同步啟用後本機公布／重播、藏答案、本機靜音與有聲播放、投影音效獨立，以及連接同步不打斷本機影片。TypeScript 與正式建置通過。未以實體手機瀏覽器驗證。

使用累積包 wedding-cat-host-preview-20261021.zip，將 app、lib、public、tests、docs 依原路徑覆蓋上傳至既有 GitHub 專案，等 Cloudflare 部署完成，再關閉舊分頁重新開啟。此包包含前版所有修正，也補上本次變更的 public/cat-memes.css。不需資料表遷移，尚未直接部署。
