# 答題速度計分與遊戲入場名單（2026-10-22）

## 快問快答計分

新出題採速度計分：答對500～1000分，越快答對越高分；答錯或逾時0分。

分數 = 四捨五入（1000 − 500 × 作答耗時／題目秒數），比例限制在0～1。耗時從伺服器出題時間到伺服器受理答案時間，不接受手機自行傳入的分數、時鐘或耗時。仍受網路及伺服器處理延遲影響。

例如20秒題：1秒答對975分、10秒750分、接近截止500分；截止後不再接受。每人每題一次，不能藉重送改分。排行榜、個人總分與主持人分數清單都使用同一套計算。

時間資料寫入既有settings的quizTiming:題目ID，與出題同交易並受題目輪次條件保護；答案保留原answers資料表。下一題後仍能依該題時間算原分數，無資料表遷移。重開問答才清除答案與計時資料；舊版沒有計時資料的作答仍按原10分呈現，不改過去資料。正式活動前若沿用測試問答，請在後台明確確認「重開問答」開始乾淨計分。

## 入場名單

完成報到後，從首頁按進遊戲、掃遊戲QR進入，或自動跟隨主持人進問答／搶答／開獎，手機會用自己的報到憑證登錄gameJoin。只瀏覽接待首頁、上傳相片或留祝福的人不因此列入遊戲名單。

同一報到身分重開、重掃或重送，仍只計一人。只接受伺服器驗證的guestId與資料庫姓名，忽略自行傳來的名字／別人ID；作答成功時亦以同交易補登，避免網路漏掉入場登錄。改報到姓名後名單也反映新姓名。

- 大螢幕「投影遊戲QR」：QR旁顯示總人數、最近三位加入者及名單。
- 問答尚未出題：等待畫面顯示入場名單與總人數。
- 人多時每頁36名、每6秒自動輪播，避免150個名字擠滿畫面。
- 作答中：顯示本題已答人數／總加入人數，保留題目空間。
- 主持活動控制：顯示總人數，展開可看入場名單。
- 賓客遊戲等待頁：確認自己已加入，看到目前總加入人數。

這是「累計已加入遊戲」而非即時在線人數，關閉網頁不會移除；重開問答也不清除已入場名單。多人同名會各自保留，公開API只提供顯示姓名，不提供guestId或憑證。不同瀏覽器仍可能是不同報到身分，沿用同一瀏覽器參與。
