# 麻將聽牌問答：五題漸進（2026-10-21）

手機主持人後台 → 摸麻將 → 麻將聽牌問答。
選題後按「出題／藏起答案」，由賓客口頭作答；主持人按「公布解答」，手機本頁與電腦專用投影同步答案及拆牌說明。上下題皆重回猜題畫面，不會自動揭答案。原本摸實體麻將的猜牌／答對／答錯仍可用，按原按鈕即切回摸牌模式。

規則：本活動採台灣16張的五組面子＋一對將眼，不計台數、花牌或其他限制；已列出的面子固定不拆。每題手牌加固定面子共16張，再摸一張胡牌。

答題畫面有牌面、固定面子與清楚規則；解答前不渲染答案／解說。主持人仍可在公開前於題庫程式或此文件核對答案。這是現場口答問答，不新增賓客手機作答或計分系統。

新增 mahjongQuiz 管理動作：嚴格驗證 index 0～4 與 phase question/answer，與切換麻將投影同交易寫入既有 settings，不需遷移。原 mahjongPhase 將恢復摸實體麻將模式。
