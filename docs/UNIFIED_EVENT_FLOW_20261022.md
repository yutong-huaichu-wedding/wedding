# 同網址、自動切活動與原生快問快答（2026-10-22）

## 賓客流程

掃既有QR → 姓名與頭像報到一次。首頁只留上傳相片、留下祝福、樂透選號三個主要按鈕，保留簡短似顏繪提醒。上方精簡為首頁／相簿／祝福／樂透。

二進由主持人切活動：

- 歡迎入席：回三個主要入口。
- 快問快答：自動進四選一，不需加入第二場遊戲或外部帳號。
- 小貓／麻將搶答：自動進「我要搶答」頁；題目看電腦投影，主持人在小貓／麻將原控制區公布，另按搶答準備與5秒倒數。
- 大樂透開獎：自動進樂透畫面，原彩券與兌獎本名沿用；正式開獎也會發布此活動。

賓客可以自己切回相簿／祝福／選號，畫面上方會有「回到活動」；同一活動不會每秒把人拉回。主持人切新活動或出下一題問答時，會再次自動跟隨。頁面原始DOM、祝福文字、選號與已選相片不因自動切頁而重建／清除。

必須保持網頁開啟與連網。鎖屏或切App不保證背景執行，回網頁後會同步最新活動。主持人與投影頁不套用賓客自動導航。

## 主持人操作

主持人控制台頂端與小貓主持頁都新增「切換賓客活動」。先選活動，再用原本的小貓／麻將／搶答控制操作內容。小貓題庫仍留在該裝置瀏覽器；本次未遷移。小貓文案改成手機搶答後上台，不再提示舉手。

後台「快問快答」可新增、編輯、刪除四選一題目與正解；題庫未開始時才能修改。既有資料庫原題目會沿用，不憑空編新人個資答案。開始前請核對原題庫；若原問答仍在進行，先確認後按「重開問答」清掉原問答作答／分數，婚禮相片、留言與彩券保留。

按「出題／下一題」，所有已報到賓客都能直接作答，晚報到者亦可加入目前題。每題預設20秒，可設10～60秒；倒數到自動公布，亦可提前截止。答對10分，不按速度加分，公布後顯示前10名排行。每人每題一次、不能改答案，伺服器驗證截止時間與輪次。倒數及公布有原生投影畫面，無需Kahoot。Kahoot舊設定相容程式保留但主要賓客介面與主持入口已隱藏。

## 技術與驗證

新增輕量 /api/activity 與 settings.eventActivity（mode/serial），公開回應無賓客憑證或ID，問答開放期間不送正解；每題關閉或倒數結束後才公開正解與排行。前景接待階段約3秒讀取、遊戲階段約1秒；背景停止，focus/visibility恢復同步。這是HTTP輪詢，實際速度受網路影響。問答回應保留原quizNext／answer邏輯相容，liveQuizNext使用新autoJoin模式、DB條件寫入阻擋重複／過期／並發出題。

134項自動測試、TypeScript及正式建置通過；涵蓋活動權限與持久化、已報到／晚報到自動進入、主持人不被切走、手動離開與回活動、草稿保留、四選一單次作答、期限、答題資料隱私、倒數公布、同時出題只進一題。另含既有150人搶答原子性測試。未在實體手機瀏覽器或Cloudflare正式環境作負載測試。
