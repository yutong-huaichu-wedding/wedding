# 麻將與小貓：固定電腦投影入口（2026-10-20）

## 此次修正

線上 app.js、cat-memes.js、cat-cloud.js 已比對為前次修復版。程式仍有兩個容易造成「沒有同步」的問題：

- 主站初次載入時會排定最長 60 秒的下一次更新。之後進入後台或投影，既有排程沒有立即取消，可能仍需等很久才讀取手機的新狀態。
- 小貓預設獨立投影依賴同台電腦 BroadcastChannel；手機雲端投影需額外啟用與複製隨機 session 連結。兩台各自開主持頁，並不代表會進入同一房間。

現在新增固定「電腦專用投影」，網址為原網站 /wedding_1212?display=1。手機的麻將指令與小貓出題會更新同一個雲端投影設定，電腦自動切換畫面。

## 上線後操作（請使用這個新流程）

1. 電腦開婚禮網站 → 主持人後台 →「投影」→「開啟電腦專用投影」。也可從「摸麻將」頁開啟。新投影分頁只顯示現場內容，可按 F11 全螢幕。
2. 手機登入主持人後台，進入「摸麻將」並按猜牌、答對或答錯。電腦會自動切換到摸麻將並顯示該結果。
3. 手機進入「小貓迷因問答」，已登入時會自動連線；按題庫的「出題」，或「將目前這題送上投影」。電腦會自動切換到這支手機正在操作的小貓題目。
4. 小貓畫面第一次出現時，在電腦按一次「啟用投影音效」。之後由手機公布答案、重播、換題即可。
5. 手機返回摸麻將按任一結果，電腦自動切回；再回小貓按出題即可切回。電腦不用重開網址或重新配對。

兩台仍需連網，手機操作頁請保持在前景。第一次出題需上傳素材；等待手機顯示已同步，再公布答案。
題庫仍以操作手機的本機資料為來源。自訂素材在電腦時先匯出完整題庫、在手機匯入。
所有原本的小貓無控制列影片、GIF 題目、Kahoot 入口與大樂透功能均保留。

## 技術與相容性

- 主站新增可喚醒的單一輪詢排程。進入後台、開啟投影、恢復分頁前景時立即讀取；操作中投影及後台使用約 1 秒排程，實際延遲仍受網路與素材載入影響。
- 新增 /api/projection，僅讀投影、麻將、樂透及 Kahoot 設定；留言投影時才讀留言，不做賓客及舊問答計分查詢。
- 麻將設定與投影模式透過同一 D1 batch 更新。小貓發布後記錄正在控制的 session，固定投影用 follow=1 自動發現。
- 只能由主持人修改投影。顯示頁不需登入，僅讀取公開現場畫面，不提供主持人操作。
- 小貓 iframe 在活動切換時保留，以保留音效授權與已載入素材；切出小貓時暫停影片，不在背景發聲。
- 主持人只是開啟小貓頁不會搶走現場投影；按出題、公布、重播或送上目前題目，才將投影切換至自己的 session。
- 小貓頁若進入瀏覽器返回快取，不會先關閉連線並撤銷媒體網址而破壞返回後同步。
- 顯示模式預設等待主持人。Kahoot 提示仍僅是加入畫面，真正題目需在 Kahoot 主持頁投影。

## 安裝

將 wedding-projection-sync-20261020.zip 解壓後的 app、lib、public 三個資料夾，一起從 GitHub 原專案根目錄 Upload files 上傳覆蓋並 Commit。
這次需要後端與前端一起更新，不能只上傳 public。等 Cloudflare 部署成功，再按 Ctrl＋F5 更新原網站，從後台開啟新的電腦專用投影。
不需資料表遷移，不變更原 D1／R2 綁定、主持人密碼，也不清除正式資料。
