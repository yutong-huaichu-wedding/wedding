# 手機直接開獎與觀看（2026-10-21）

## 操作

手機開啟線上婚禮網站，進入主持人後台 → 樂透控制。依序開放選號、截止、開始開獎；下方「手機開獎畫面」會直接顯示吸球動畫及得獎者，不再強制跳入投影模式。動畫結束後可在同頁按「開下一個獎（保留彩券）」。不必另外開電腦或投影。

電腦如已開啟 ?display=1 專用投影，仍依伺服器發布的同一份結果與時間同步。賓客完成報到後，可從「互動遊戲 → 幸福大樂透」直接觀看。主持人登入後即使沒有賓客報到資料，也能前往一般遊戲頁。
