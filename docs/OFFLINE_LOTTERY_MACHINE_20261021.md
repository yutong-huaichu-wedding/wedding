# 無手機代投與吸球開獎動畫（2026-10-21）

## 代投注

主持人登入 → 樂透控制 → 幸福投注站 →「沒有手機／尚未報到：直接填本名代投」。輸入本名，手選六碼或電腦選號，可代填祝福，確認送出。成功後顯示本名與排序號碼供核對；姓名／號碼／祝福只在成功後清空。

賓客可先在紙上寫本名與六個號碼，工作人員在截止前登錄。紙本未登錄不算完成投注。已報到賓客仍可從同一選單挑選其原身分代投。

伺服器只接受已登入主持人的 proxyTicket；offline:true 會在同一 D1 交易建立賓客身分、彩券與選填祝福，不回傳登入憑證、不變更工作人員的賓客登入。姓名正規化防重、每身分一張、截止與號碼驗證共用既有規則；重複、截止或祝福失敗均不留下額外離線賓客。無資料表遷移。

## 吸球開獎

新增 public/lottery-draw.js/css，透明球槽內 49 顆球攪動，選中的球從中央吸入上方管道，再到右側展示槽，公布號碼後排入六碼列。先攪動 2.4 秒，每球 4.2 秒，整場約 28 秒。

動畫只呈現既有伺服器結果，不自行抽號或更動原本「從有效彩券挑一整張」規則。各畫面按同一 startedAt 計算進度，中途加入會接目前進度，不重播先前球。DOM 在輪詢間重用、完整結束後不再排動畫幀、背景分頁停止排幀，支援減少動態效果。切換投影活動會清理開獎元件。

樂透控制加入「試播吸球動畫（不會正式開獎）」連結：/lottery-preview.html。只用示範號碼、沒有 API 寫入，可在部署後先預演，勿為了測動畫而重設正式彩券。
