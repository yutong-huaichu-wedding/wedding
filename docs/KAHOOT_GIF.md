# Kahoot! 入口與小貓題目動圖（2026-10-20）

本包包含先前的小貓跨裝置同步、摸麻將，以及這次 Kahoot! 入口／GIF 題目修改。尚未部署到正式網站。

## 改用 Kahoot!

原本婚禮網頁內建的快問快答頁面、題庫編輯、分數顯示、問答投影及舊試玩入口均已移除。
問答改由 Kahoot! 進行；婚禮網站僅提供加入連結與 PIN 提示，不會替你建立或主持 Kahoot!，也不會自動搬移舊題目或同步 Kahoot! 分數。

1. 先在 Kahoot! 建立題目，於婚禮現場開啟遊戲。
2. 從遊戲大廳複製「加入連結」，不要複製題庫編輯或題目分享頁。
3. 婚禮網站登入主持人 →「⚡ Kahoot!」，貼上加入連結，可另填本場 Game PIN 提示，按「儲存並更新賓客入口」。
4. 賓客打開「互動遊戲」→「Kahoot!」→「前往 Kahoot! 參加遊戲」，會在新分頁開啟參賽頁；婚禮網站保留在原分頁。
5. 電腦另開 Kahoot! 的主持頁並投影其題目、倒數及排行榜。婚禮後台的「Kahoot! 加入提示」只是進場說明畫面，並非內嵌的正式 Kahoot! 題目畫面。

未提供專用連結時，預設為 https://kahoot.it/，賓客輸入現場公布的 PIN 即可。
PIN 改變時，更新本場加入連結及 PIN 提示。設定儲存在既有雲端 settings 表，主持人手機及賓客頁會讀取同一設定。
連結僅接受 HTTPS 的 kahoot.it／www.kahoot.it，避免貼錯網站或帶入腳本；PIN 可空白，或輸入 4～10 位數字。

## 自行上傳小貓題目 GIF

1. 小貓迷因問答 → 題庫找到想改的題目 →「編輯／換素材」。
2. 在「題目照片／GIF 動圖」選擇自己的 GIF（8MB 以下），也可使用動畫 WebP 或一般照片。
3. 下方「題目照片／動圖試看」會顯示原始動畫，確認後按「儲存這道題目」。
4. 按「出題」，主持人預覽及電腦投影會保留 GIF 原始動畫，不再擷取第一格當靜態照片。動畫播放次數取決於原始檔案設定。
5. 題目動圖沒有聲音；公布答案後仍播放另外上傳的有聲 MP4／WebM 影片。

照片／動圖可獨立替換，不必重新選答案影片。使用手機當控制器時，題目檔案須在該手機的題庫；可先在電腦匯出完整備份、再到手機匯入。
跨裝置投影使用先前加入的「啟用手機跨裝置同步」功能，GIF 會透過原始檔案上傳，不進行轉檔或壓平成靜態圖。
